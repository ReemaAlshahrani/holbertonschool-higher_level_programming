# Python - Data Structures: Lists, Tuples

This directory contains projects and exercises about basic data structures in Python, focusing on Lists and Tuples.

## Requirements
* All files are interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.8.5).
* All code follows the `pycodestyle` style guide.

## Tasks

| File | Description |
| --- | --- |
| `0-print_list_integer.py` | A function that prints all integers of a list, one integer per line. |
