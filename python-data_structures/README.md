# Python - Data Structures: Lists, Tuples

This directory contains solutions for tasks on Python data structures (Lists and Tuples) as part of the **Holberton School** curriculum.

---

## Tasks Overview

### 0. Print a list of integers
* **File:** `0-print_list_integer.py`
* **Description:** A function that prints all integers of a list, one per line, using `str.format()`.

### 1. Secure access to an element in a list
* **File:** `1-element_at.py`
* **Description:** A function that retrieves an element from a list like in C. Returns `None` if the index is negative or out of range.

### 2. Replace element
* **File:** `2-replace_in_list.py`
* **Description:** A function that replaces an element of a list at a specific position without modifying the original list if the index is invalid.

### 3. Print a list of integers... in reverse!
* **File:** `3-print_reversed_list_integer.py`
* **Description:** A function that prints all integers of a list in reverse order using `str.format()`.

### 4. Replace in a copy
* **File:** `4-new_in_list.py`
* **Description:** A function that replaces an element in a list at a specific position without modifying the original list by returning a new copy.

### 5. Can you C me now?
* **File:** `5-no_c.py`
* **Description:** A function that removes all characters `c` and `C` from a string without using `str.replace()`.

### 6. Lists of lists = Matrix
* **File:** `6-print_matrix_integer.py`
* **Description:** A function that prints a 2D matrix of integers formatted with spaces and `str.format()`.

### 7. Tuples addition
* **File:** `7-add_tuple.py`
* **Description:** A function that adds 2 tuples element-wise for the first two integers, handling tuples smaller or larger than 2 elements.

### 8. More returns!
* **File:** `8-multiple_returns.py`
* **Description:** A function that returns a tuple containing the length of a string and its first character (or `None` if the string is empty).

### 9. Find the max
* **File:** `9-max_integer.py`
* **Description:** A function that finds the largest integer in a list without using the built-in `max()` function.

### 10. Only by 2
* **File:** `10-divisible_by_2.py`
* **Description:** A function that finds all multiples of 2 in a list and returns a new list of boolean values (`True` or `False`).

### 11. Delete at
* **File:** `11-delete_at.py`
* **Description:** A function that deletes the item at a specific position in a list without using `pop()`.

### 12. Switch
* **File:** `12-switch.py`
* **Description:** A 5-line program that swaps the values of variables `a` and `b`.
