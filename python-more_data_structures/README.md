my ptoject# Python - More Data Structures: Set, Dictionary

This repository contains tasks for learning and practicing Python's advanced data structures, specifically **Sets** and **Dictionaries**, along with functional tools like `map`, `lambda`, and `filter`.

## Summary of Tasks (0 to 12)

| Task | File | Description |
| :--- | :--- | :--- |
| **0. Squared simple** | `0-square_matrix_simple.py` | Computes the square value of all integers of a matrix using a new matrix. |
| **1. Search and replace** | `1-search_replace.py` | Replaces all occurrences of an element by another in a new list. |
| **2. Unique addition** | `2-uniq_add.py` | Adds all unique integers in a list only once for each integer using `set()`. |
| **3. Present in both** | `3-common_elements.py` | Returns a set of common elements in two sets using the intersection operator (`&`). |
| **4. Only differents** | `4-only_diff_elements.py` | Returns a set of all elements present in only one set using symmetric difference (`^`). |
| **5. Number of keys** | `5-number_keys.py` | Returns the number of keys in a dictionary using `len()`. |
| **6. Print sorted dictionary** | `6-print_sorted_dictionary.py` | Prints a dictionary with keys ordered alphabetically. |
| **7. Update dictionary** | `7-update_dictionary.py` | Replaces or adds key/value pairs in a dictionary. |
| **8. Simple delete by key** | `8-simple_delete.py` | Deletes a specific key in a dictionary if it exists. |
| **9. Multiply by 2** | `9-multiply_by_2.py` | Returns a new dictionary with all values multiplied by 2 using dictionary comprehension. |
| **10. Best score** | `10-best_score.py` | Returns the key with the biggest integer value in a dictionary. |
| **11. Multiply by using map** | `11-multiply_list_map.py` | Returns a list with all values multiplied by a number using `map` and `lambda` without loops (max 3 lines). |
| **12. Roman to Integer** | `12-roman_to_int.py` | Converts a Roman numeral string to an integer handling subtraction rules. |
