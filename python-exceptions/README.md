# Python - Exceptions

## Description
This project focuses on understanding and implementing **Exception Handling** in Python 3.

## Tasks

| File | Description |
| :--- | :--- |
| `0-safe_print_list.py` | Function that prints `x` elements of a list safely using `try / except`. |
| `1-safe_print_integer.py` | Function that prints an integer with `"{:d}".format()` safely. |
| `2-safe_print_list_integers.py` | Function that prints the first `x` integers of a list, skipping non-integers. |
| `3-safe_print_division.py` | Function that divides 2 integers and prints result in `finally` block. |
| `4-list_division.py` | Function that divides element by element 2 lists and handles exceptions. |
| `5-raise_exception.py` | Function that explicitly raises a TypeError exception. |
| `6-raise_exception_msg.py` | Function that raises a NameError exception with a custom message. |
| `100-safe_print_integer_err.py` | Function that prints an integer safely and logs errors to stderr. |
| `101-safe_function.py` | Function that executes another function safely and catches all runtime exceptions. |
| `102-magic_calculation.py` | Function matching Python bytecode logic using try-except and loops. |
