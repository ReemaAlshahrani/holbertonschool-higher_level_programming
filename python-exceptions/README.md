# Python - Exceptions

## Description
This project focuses on understanding and implementing **Exception Handling** in Python 3. It covers the difference between syntax errors and runtime exceptions, how to use `try`, `except`, `raise`, and `finally` blocks, and how to safely write code that handles unexpected errors gracefully without breaking execution.

## Learning Objectives
* Difference between errors and exceptions.
* What exceptions are and how to use them.
* When and why we need to use exceptions.
* How to correctly handle exceptions.
* Purpose of catching exceptions.
* How to raise built-in exceptions.
* Implementation of clean-up actions after an exception.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`
* All files interpreted/compiled on **Ubuntu 20.04 LTS** using `python3` (version 3.8.5).
* All files end with a new line.
* The first line of all execution files must be `#!/usr/bin/python3`.
* Code formatted according to `pycodestyle` (version 2.7.*).
* All files must be executable.
