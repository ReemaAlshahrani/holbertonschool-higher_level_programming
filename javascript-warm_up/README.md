# JavaScript - Warm Up

This repository contains basic JavaScript scripts and exercises, starting from introductory scripts up to file exporting, functions, objects, and classes.

## Files Overview

| File Name | Description |
| :--- | :--- |
| `0-javascript_is_amazing.js` | Prints "JavaScript is amazing" to the console. |
| `1-multi_languages.js` | Prints 3 lines about different programming languages (C, Python, JavaScript). |
| `2-arguments.js` | Prints whether arguments are passed, passed, or multiple arguments are passed. |
| `3-value_argument.js` | Prints the first argument passed to the script, or "No argument" if missing. |
| `4-concat.js` | Concatenates two arguments passed to the script in a specific format ("is"). |
| `5-to_integer.js` | Converts the first argument to an integer and prints it, or prints "Not a number". |
| `6-multi_languages_loop.js` | Prints 3 lines using an array and a loop (`for` loop). |
| `7-multi_c.js` | Prints `x` times "C is fun", where `x` is parsed from the command line. |
| `8-square.js` | Prints a square of size `x` using the character 'X'. |
| `9-add.js` | Prints the addition of two integers passed as arguments. |
| `10-factorial.js` | Computes and prints a factorial using recursion. |
| `11-second_biggest.js` | Finds and prints the second biggest integer in the list of arguments. |
| `12-object.js` | Replaces a value inside a JavaScript object. |
| `13-add.js` | Exports a function that adds two integers to make it available for other files. |
