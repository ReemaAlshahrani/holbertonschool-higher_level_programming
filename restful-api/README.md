# RESTful API Directory

This directory contains tasks and practical exercises focused on web communication, API consumption, server development, and API security using Python.

## Directory Contents

* Task 0: Basics of HTTP/HTTPS (Theoretical concepts, no files created)
* Task 1: Consume data from an API using command line tools (cURL practice, no files created)
* task_02_requests.py: Python script to fetch data from an external API and export it to a CSV file.
* task_03_http_server.py: A basic HTTP server built using Python's standard http.server module.
* task_04_flask.py: A lightweight RESTful API built using the Flask web framework.
* task_05_basic_security.py: A secure Flask API implementing Basic Authentication, JWT token-based authentication, and Role-Based Access Control.

## Requirements and Dependencies

To run the scripts in this directory, ensure you have Python 3 installed along with the following packages:
* requests
* Flask
* Flask-HTTPAuth
* Flask-JWT-Extended
