# JavaScript DOM Manipulation

This project focuses on learning how to interact with and manipulate the DOM using JavaScript through various interactive tasks and exercises.

| File Name | Description |
| :--- | :--- |
| `0-script.js` | Updates the text color of the header element to red. |
| `1-script.js` | Changes the header text color to red when clicking a specific element. |
| `2-script.js` | Adds the `red` class to the header element on a click event. |
| `3-script.js` | Toggles the header class between `red` and `green` on click. |
| `4-script.js` | Appends a new `li` item to a list when clicking an add button. |
| `5-script.js` | Updates the header text content when clicking an update button. |
| `6-script.js` | Fetches and displays a Star Wars character's name using the Fetch API. |
| `7-script.js` | Fetches and lists all Star Wars movie titles using the Fetch API. |
| `8-script.js` | Fetches a greeting translation and displays it in the DOM. |
| `100-script.js` | Manages list elements dynamically (adds, removes the last item, clears all). |
| `101-script.js` | Fetches and displays a greeting translation based on a selected language option. |
