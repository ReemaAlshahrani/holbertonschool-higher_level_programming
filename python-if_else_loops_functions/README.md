# Python - if/else, loops, functions

## Description
This directory contains tasks focused on learning basic control flow structures in Python (such as condition testing, branching, and iterative loops) along with clean functional implementations and low-level character conversions without external library dependencies.

## Requirements
- All files are interpreted and executed on **Ubuntu 20.04 LTS** using `python3` (version 3.8.5).
- All source code complies strictly with the `pycodestyle` format guidelines (PEP 8).
- Every script has been granted executable permissions via `chmod +x`.

## Project Structure

| File Name | Description |
| :--- | :--- |
| `0-positive_or_negative.py` | Assigns a random signed number and prints whether it is positive, negative, or zero. |
| `1-last_digit.py` | Computes and evaluates the absolute last digit of a signed integer with dedicated negative modulo logic. |
| `2-print_alphabet.py` | Prints the lowercase ASCII alphabet using exactly one loop and a formatted print expression. |
| `3-print_alphabt.py` | Prints the lowercase alphabet while filtering out the characters `q` and `e`. |
| `4-print_hexa.py` | Loops through values 0 to 98 and formats them continuously in both base-10 and base-16 formats. |
| `5-print_comb2.py` | Prints consecutive sequential numbers from 00 to 99 with custom string zero-padding configuration. |
| `6-print_comb3.py` | Computes all combinations of two distinct digits dynamically using optimized structural nested indexing. |
| `7-islower.py` | Function that returns `True` if a character string input is purely a lowercase English letter. |
| `8-uppercase.py` | Loops over a raw string input and forces conversion into full uppercase directly via ASCII math. |
| `9-print_last_digit.py` | Evaluates, prints, and returns the numerical tail or last digit unit value from signed variables. |
| `10-add.py` | Arithmetic utility function that sums two passed variables and forwards the structural result. |
| `11-pow.py` | Computes base-value structures to the power of variable exponents natively using the standard operator. |
| `12-fizzbuzz.py` | Classic logic challenge that prints sequence increments while re-mapping overlapping integer divisors. |
| `100-print_tebahpla.py` | Loops backwards across character sets, alternating lower and upper casing on odd/even positions. |
| `101-remove_char_at.py` | Creates copies of raw character chains while removing specified indices safely via explicit boundary protections. |
