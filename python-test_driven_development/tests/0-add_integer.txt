==============================
How to Use 0-add_integer.py
==============================

This module provides the ``add_integer()`` function, which adds two numbers together.

Usage
=====

Importing the function:
    >>> add_integer = __import__('0-add_integer').add_integer

Normal Addition (Integers):
    >>> add_integer(1, 2)
    3
    >>> add_integer(100, -2)
    98
    >>> add_integer(0, 0)
    0
    >>> add_integer(-5, -5)
    -10

Default Argument (b = 98):
    >>> add_integer(2)
    100
    >>> add_integer(-100)
    -2

Float Arguments (Casted to Int):
    >>> add_integer(100.3, -2)
    98
    >>> add_integer(2.9, 3.1)
    5
    >>> add_integer(-100.9)
    -2
